# 定点运算示例

模型边界处使用 16 位有符号数，其中包含 14 个小数位。

```text
1.0       -> 16384  -> 0x4000
-1.0      -> -16384 -> 0xC000
0.5       -> 8192   -> 0x2000
最大值    -> 32767  -> 0x7FFF
最小值    -> -32768 -> 0x8000
```

复数乘法计算如下：

```text
(wr + j*wi) * (sr + j*si)
real_integer = wr*sr - wi*si
imag_integer = wr*si + wi*sr
```

两个结果最初都包含 28 个小数位。4 个复数乘积在不进行中间截位的情况下完成累加。最终累加结果右移 14 位，并采用最近值舍入；当数值恰好位于两个整数中间时，向远离零的方向舍入。

下面是去除 1 个小数位时的例子：

```text
 3 / 2 ->  2
 1 / 2 ->  1
-1 / 2 -> -1
-3 / 2 -> -2
```

完成舍入后，大于 `32767` 的结果饱和为 `32767`，小于 `-32768` 的结果饱和为 `-32768`。

## Q1.14格式的定量验证

new第10阶段使用120000组场景验证当前格式。预编码矩阵Frobenius范数为0.9、QAM符号为单位平均功率时，QPSK、16QAM和64QAM共75000组用例均未饱和，P99端到端EVM低于`3e-4`。因此Q1.14适合作为当前归一化数据通路格式。

该结论不适用于无功率约束的满幅矩阵和满幅符号。全幅压力输入中99.804%的用例发生饱和，所以上游必须完成矩阵/信号缩放；否则应增加可配置缩放或更宽输出。完整数据见 `docs/stage10_numeric_search.md`。
